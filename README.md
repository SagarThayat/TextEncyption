# 🔐 Text Encryption Project

A Python-based project that demonstrates multiple encryption techniques including **AES**, **RSA**, and **SHA hashing**.

---

## 🚀 Features

* 🔑 AES Encryption & Decryption
* 🔐 RSA Encryption & Decryption
* 🔒 SHA Hashing
* 📁 Modular code structure
* 🧠 Easy to understand implementation

---

## 📂 Project Structure

```
TEXTENCRYPTION/
│── aes_module.py     # AES encryption logic
│── rsa_module.py     # RSA encryption logic
│── sha_module.py     # SHA hashing
│── main.py           # Main program
```

---

## 🛠️ Technologies Used

* Python 3
* Cryptography concepts (AES, RSA, SHA)

---

## ▶️ How to Run

1. Clone the repository:

```
git clone https://github.com/your-username/TextEncyption.git
```

2. Navigate to project folder:

```
cd TextEncyption
```

3. Run the project:

```
python main.py
```
